# Visual Scene Compiler

This is a JavaFX application that parses a custom scene description language and renders the result visually.

The goal of this project was to simulate how a simple compiler works by taking structured input, interpreting it, and generating graphical output.

## What It Does

- Accepts structured text input describing shapes and layouts  
- Parses the input into commands  
- Renders the scene using JavaFX  
- Displays the final graphical output in a GUI  

## Tech Used

- Java  
- JavaFX  
- Parsing and input processing  
- Object-Oriented Programming  

## What I Focused On

- Designing a simple input language  
- Parsing structured commands into usable data  
- Connecting parsing logic to graphical rendering  
- Building a clean flow from input → processing → output  

## How to Run

1. Clone the repository  
2. Open in IntelliJ IDEA  
3. Run the main application class  
4. Enter scene commands and view the rendered result
